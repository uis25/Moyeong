# 원본과 의도적으로 다르게 한 부분

React 변환 시 원본(`original/original/index.html`)과 **일부러** 다르게 만든 동작 목록입니다.
여기 없는 차이는 모두 버그이므로 `npm run compare`로 찾아 고쳐야 합니다.

| # | 항목 | 원본 | React | 이유 |
|---|---|---|---|---|
| 1 | 버튼을 누른 뒤 포커스 | 화면 일부를 innerHTML로 다시 그려서 누른 버튼이 새 요소로 바뀌고 포커스가 사라짐 (Tab을 누르면 페이지 처음부터 다시 시작) | 누른 버튼에 포커스가 남음 (Tab을 누르면 바로 다음 요소로 이동) | 키보드 사용자 접근성. 마우스 사용 시 화면 차이는 없음 |
| 2 | 후기 공유 저장소 | 아티팩트 안에서 열면 `window.claude.use("db")`로 후기를 다른 사용자와 공유 | localStorage에만 저장 (원본을 아티팩트 밖에서 열었을 때와 같은 동작) | 아티팩트 전용 API라 일반 웹에서는 쓸 수 없음. 나중에 `src/services/`를 서버 API로 교체할 예정 |
| 3 | 웹폰트 불러오기 | Google Fonts CDN (Noto Sans KR 400/500/700/800) | npm 패키지 `@fontsource/noto-sans-kr` (같은 굵기) | CDN 대신 npm 패키지로 관리. 화면 비교 결과 동일 |
| 4 | 정책 카드 맨 위 배지 | 제목 위에 자격 판정 배지(기본 조건 일치·추가 확인 필요·조건 불일치)와 모집 상태 배지(모집 중 D-n·마감 임박·접수 예정·마감·확인 필요)를 표시 | 자격 판정 배지는 표시하지 않음. 모집 상태 배지는 그대로 표시 (상세 보기 안의 "내 조건과 비교" 배지는 그대로) | 요청에 따른 디자인 수정. 비교 스크립트는 원본 쪽에도 같은 배지를 뺀 뒤 비교 |
| 5 | 공식 링크가 없는 카드 | "공식 링크 없음" 글자 버튼 | 상세 보기의 참고 링크처럼 흐린 "공식 공고문 ↗" 버튼 (누를 수 없음) | 요청에 따른 디자인 수정. 비교 스크립트는 원본 쪽에도 같은 변경을 적용한 뒤 비교 |
| 6 | 모집 상태 배지 색 (정책 카드 · 홈 '지금 확인할 정책') | 카드: 마감 임박만 주황, 나머지는 회색. 홈: 모집 중 초록, 마감 임박 주황, 나머지 회색 | 두 곳 모두 같은 규칙: 모집 중 초록, 마감 임박 주황(그대로), 접수 예정 흐린 초록(모집 중 색에 투명도 0.45), 확인 필요 노랑, 마감 회색(그대로) | 요청에 따른 디자인 수정. 비교 스크립트는 원본 쪽에도 같은 색을 적용한 뒤 비교 |
| 7 | 정책 목록 정렬 | "마감"만 맨 뒤로 보내고, 나머지 상태(모집 중·접수 예정·확인 필요)는 구분하지 않음. 조건을 입력하지 않으면 모두 동점이라 데이터 파일 순서대로 나옴 | 모집 상태 순서(마감 임박·모집 중 → 접수 예정 → 확인 필요 → 마감)를 추가. 나에게 맞는 정책순은 내 조건 일치도 → 검색 점수(검색어가 있을 때) → 모집 상태 순서 순, 마감 임박순·최신 등록순은 모집 상태 순서 → 마감일·등록일 순 | 요청에 따른 수정 (조건·검색어가 없을 때 모집 중 정책이 맨 위에 오도록, 검색할 때는 검색어와 잘 맞는 순서가 먼저). 비교 스크립트는 원본 쪽 정렬에도 같은 규칙을 적용한 뒤 비교 |
| 8 | 내 조건의 모집 상태 칩 | 모집 중·마감 임박·접수 예정·마감·확인 필요 5개 | "확인 필요" 칩 제거 (4개). 예전에 "확인 필요"를 골라 저장했으면 불러올 때 자동으로 풀림. "정책 모아보기" 메뉴 안내판의 "신청 상태로 좁히기" 설명에서도 "확인 필요"를 뺌 | 요청에 따른 수정. 비교 스크립트는 원본 쪽 칩과 안내판 문구에서도 같은 항목을 뺀 뒤 비교 |
| 9 | 화면을 다시 그릴 때 정책 상세·선배 후기 | 필터·관심·신청 기록·후기 버튼(별점·키워드 선택 포함) 등을 누를 때마다 목록 전체를 새로 만들어, 열려 있는 상세 영역의 등장 애니메이션이 다시 재생되고 후기 영역도 새로 그려짐 | 바뀐 부분만 다시 그림. 상세 영역 애니메이션은 처음 열 때만 재생되고, 후기 영역도 새로 그려지지 않음. 요소가 유지되므로 브라우저의 스크롤 고정(scroll anchoring)이 동작해 위쪽 내용 높이가 바뀌어도 보던 내용이 제자리에 있음 | 요청에 따른 수정 (누를 때마다 깜빡이던 문제). 비교 스크립트는 스크롤 고정을 양쪽 모두 끄고 비교 |
| 10 | 숫자가 아닌 나이 입력 | 입력칸에 숫자가 아닌 글자(예: `1e`)를 넣으면 즉시 지워짐 | 지우지 않음 (브라우저 기본 숫자 입력칸 동작, 조건에는 빈 값으로 반영) | 요청에 따른 수정 (입력 중 글자가 사라지던 문제) |
| 11 | 달력 날짜 팝업 | 팝업이 열린 채 상단 숫자·`내 조건 설정`·`관심 정책` 등으로 이동하면 선택이 남아, 달력으로 돌아오면 팝업이 다시 열려 있음 | 다른 화면으로 가면 팝업이 닫힘 (보고 있던 달은 유지) | 요청에 따른 수정. 비교 스크립트는 원본 쪽에도 같은 동작을 적용한 뒤 비교 |
| 12 | 정책 상세의 안내 문구 | 후기 작성 폼 아래 "공유 저장소에 연결되지 않아 후기는 이 기기(localStorage)에만 저장되고…" 문구, 신청 기록 칩 아래 "직접 고르는 진행 상태 (다시 누르면 기록 삭제, 이 기기에만 저장)" 문구 | 두 문구 모두 표시하지 않음 | 요청에 따른 수정. 비교 스크립트는 원본 쪽에서도 같은 문구를 뺀 뒤 비교 |
